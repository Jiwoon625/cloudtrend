# CloudTrend V8 섹터 과열 페널티 백테스트

## 목적

기존 Vf 주식 기술점수 9.5점 체계를 10점 만점으로 전환하되, 섹터 점수를 적극 가산하지 않고 과열 섹터 추격매수를 낮추는 0.5점 페널티 슬롯으로 테스트한다.

## 점수 체계

```text
V8 점수 = 기존 Vf 9.5점 + 섹터 기본 슬롯 0.5점 - 섹터 과열 페널티 0.5점
```

- 정상/중립/소외 섹터: 기존 Vf 점수 + 0.5점
- 과열 섹터: 기존 Vf 점수 + 0.5점 - 0.5점 = 기존 Vf 점수 유지
- 데이터 없음: 기본 슬롯 0.5점을 유지한다. 데이터 결측을 과열로 간주하지 않는다.

## 섹터 과열 정의

섹터 과열은 같은 날짜의 섹터 `Price Leadership` 점수가 기준 이상일 때로 정의한다.

비교 기준:

- Price Leadership ≥ 70
- Price Leadership ≥ 75
- Price Leadership ≥ 80
- Price Leadership ≥ 85

페널티 없는 10점 기준 baseline도 함께 계산한다.

## 기본 전략

기본 전략은 다음 조합이다.

```text
75 Onset 진입
상승청산 90점
하락청산 30점
최대보유 30영업일
가격손절 사용하지 않음
```

점수는 10점 만점 기준으로 환산된다.

- 75 = 7.5점
- 90 = 9.0점
- 30 = 3.0점

## 비교 조합

다음 조합을 모두 비교한다.

| 항목 | 값 |
|---|---|
| 진입 Onset | 65, 75 |
| 상승청산 | 95, 90, 85 |
| 하락청산 | 35, 30, 25 |
| 최대보유 | 20, 30, 40 영업일 |
| 섹터 과열 기준 | Price Leadership 70, 75, 80, 85 |
| Baseline | 페널티 없음 |

## 진입/청산 방식

기존 V6 전략과 같은 방식으로 처리한다.

- 신호일 종가 기준으로 점수 교차를 확인한다.
- 진입은 다음 거래일 시가에 체결된 것으로 가정한다.
- 상승/하락 점수 청산도 전일 점수 교차를 확인한 뒤 다음 거래일 시가에 청산한다.
- 최대보유 청산은 계획 만기일 종가에 청산한다.
- 가격손절과 ATR trailing stop은 사용하지 않는다.

## 해석 포인트

1. `Price Leadership ≥ 80` 페널티가 기본 전략의 초과수익률과 손익비를 개선하는지 확인한다.
2. 65 Onset과 75 Onset의 거래 수, 평균수익률, 초과수익률을 비교한다.
3. 상승청산 85/90/95 중 어느 쪽이 추세 수익을 더 잘 보존하는지 확인한다.
4. 하락청산 25/30/35 중 어느 쪽이 손실 방어와 노이즈 회피의 균형이 좋은지 확인한다.
5. 최대보유 20/30/40일 중 어느 기간이 과열 페널티 체계와 가장 잘 맞는지 확인한다.
