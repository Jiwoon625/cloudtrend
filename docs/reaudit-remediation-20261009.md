## 미국 우선순위 추가 대조

S2의 체결·미리보기 수정 뒤 스크리너 기본 정렬에도 Core/Beta 동점의 TK 비교가 빠진 것을 확인했다. 후보 공통 비교기를 UI와 주문 생성에서 공유한다. A0/A2는 Core↓→Beta↓→TK↓→코드↑, B3는 Core↓→Beta↓→RelVol↓→코드↑이며 수동 표 정렬은 명시된 사용자 조회 상태로 구분하고 기본순 복원을 제공한다. 신호 생성부터 pending 순위 저장, 다음 시가 실행과 미리보기까지 A0/B3 동점 사례를 검증한다. 당일 종가 점수를 시가 우선순위에 사용하지 않는다. 공유 함수 추출 전후 엔진 순서는 동일하며 동결 계약과 베타 계산은 보존한다.

## PR234 독립 재검증에서 추가된 잔여

최신 Notion 재감사 상단의 11:54–12:00 UTC 독립 검증을 추가 대조했다. 신규 KR 공통 계약의 보유일은 체결에 쓰는 종목 가격 관측 행으로 센다. H60의 종가와 이월 청산일의 종가가 모두 없을 때 59로 표시되던 값을 61번째 관측 시가 청산·보유일61로 검증한다. 기존 베타 계산 경로는 그대로 둔다.

미국의 기존 trade.coreRank와 position.entryCoreRank는 실행일 종가 순위라는 의미를 보존한다. 신규 계약에서 매매 detail.signalPriority 및 보유 entrySignalDate/entrySignalPriority를 별도 보존하고 기존 coreRank의 기준을 명시한다. 실행일 Core 0.99, 신호일 Core 0.95가 각각 남는 회귀를 추가했다. 해당 종가 순위는 시가 수량 배정에 사용하지 않는다. 과거 연구의 동일전략 비교는 운영 날짜 경계를 임의 변경하지 말고 연구 전용 옵션을 별도 검토해야 한다. 이번 수정에서 CM 연구나 과거 전체기간 백테스트를 실행하지 않는다.

ETF에도 섹터·M0 최소·환경점수 최소·20일 평균 거래대금 최소 필터를 추가하고 변경 시 첫 페이지로 돌아간다. 모르는 수치는 0으로 승격하지 않고 양수 최소값 필터에서 제외한다.
