## 보존 경계

베타 원장·동결 계약·기존 실제 체결과 취득원가는 변경하지 않는다. DB 쓰기/가상 실거래 입력/원장 초기화/새 마이그레이션은 없다. 실제 새 성과의 배정금액·통화·환율은 미확정 유지한다. CM 연구 실행과 섹터 기능은 변경하지 않으며 섹터 title/OG의 옛 브랜드만 정리한다.

## 검증과 한계

결함별 재현 검사와 기존 계산·게시·원장·화면 검사를 사용한다. GitHub Actions의 DB 원자성/RLS 검사는 격리 PostgreSQL에서 수행한다. 브라우저는 사용하지 않으며 인증 화면 실제 클릭·모바일 간격·내보내기 조작을 완료했다고 주장하지 않는다. 운영 실자료 첫 신규 세션, 실제 배정현금 기준점과 일별 관측은 각각 유효 자료 도착과 주말 대조 후 확인한다. 최종 CI·병합·배포 결과는 원본 Notion 재감사 페이지에 기록한다.
