### KOSPI

- 청산: 9.5 상향돌파 다음 거래 가능 시가 / 진입일 포함 종목 가격행 60번째 관측 종가(H60). 하방 점수 청산 없음.
- 배정: 초기자금 ÷ 최대 보유 종목 수. 기본 한국 합산 30종목, 후보가 KOSPI이면 동일 섹터 3종목. 기술점수↓ → 우선점수↓ → 종목코드↑.

### KOSDAQ

- 확인: 2026-09-17 채택 기록 기준 E8 / U9.0 / D3.0 / H60. 과거 9.5/2.5 연구와 구분.
- 청산: 9.0 신규 상향돌파 또는 3.0 하향 이탈 다음 거래 가능 시가 / 종목 가격행 60번째 관측 종가.
- 배정: 초기자금 ÷ 최대 보유 종목 수. 한국 합산 기본 30종목, 후보가 KOSDAQ이면 동일 섹터 6종목. 기술점수↓ → 우선점수↓ → 종목코드↑.

### 미국 A0

- 진입: Core 상위 20% 신규 진입 + Beta 상위 10% + TK 상위 20% + 공통 적격 → 다음 미국 정규장 시가
- 확인: 추가 하루 확인 없음. 전일 Core와 당일 Core를 같은 횡단면 정책으로 비교. 첫 관측을 신규 돌파로 간주하지 않음.
- 청산: Core 상위 30% 밖·산정 불가 또는 Beta 상위 40% 밖 3일 연속. 다음 정규장 시가, 부분체결 잔량 이월.
- 배정: 초기 USD 자금 ÷ 고정 20슬롯. 정기 리밸런싱·자금 마련용 부분매도 없음. Core↓ → Beta↓ → TK↓ → 종목코드↑. 전일 ADV20의 1% 참여한도.

### ETF V0.2

- 진입: M0 절대점수 80 신규 돌파(원신호) → 다음 한국 거래일 확인 → 진입 준비 → 이후 거래 가능한 시가
- 확인: 확인일 M0≥80, 기초지수≥MA60, 수정주가·KRX 필수자료 적격. M0=기술62.5+우선7.5+건전성15+환경15.
- 청산: 기초지수 종가 MA60 하회 → 다음 거래 가능한 시가. 고정 만기·고점수 청산 없음.
- 배정: 최대 10종목. 목표비중 10%×min(1,15%÷연환산 변동성). 확인일 평균 거래대금↓ → 종목코드↑. 교체·추가매수 없음.

### 공통 실행·자료·기록

- 동일 종목·날짜 중복은 입력 순서대로 뒤 행의 비어 있지 않은 관측값을 병합. 최종 선택 가격까지 대사.
- 예산·비용·현금 한도 내 정수 수량만 매수. 목표 예산에 1주가 들어오지 않으면 매수하지 않음. 금액은 8자리 고정소수점 연산.
- 한국주식·ETF 진입 시 거래량 양수·실제 관측 시가 필수. 거래량0·미관측·시가 결측이면 체결하지 않고 유효한 미체결 주문 이월.
- 한국주식·ETF에서 다른 종목은 정상인데 보유 종목 거래량이0/미관측 또는 자료가 누락되면 전날 시가 기준 모델 가정 청산. 누락 확인일에 기록하며 과거 현금을 소급 생성하지 않음. 실제 보상은 Notion 실제 원장에 기록.
- 시가 청산 후 시가 매수. 종가 청산 대금은 다음 세션부터 사용. 미체결 청산 이월. 점수청산 시가와 H60 종가가 겹치면 시가 우선. 시장 전체 자료 미수신은 개별 종목 청산으로 오인하지 않음.
- 모델 비용 기본 편도0.15%, 왕복0.30%. 실제 수수료·보상은 입력된 실제 금액 유지.
- 가격·기술 판단은 저녁에도 표시. KRX 의존 자격은 미확정 유지하며 이 표시가 Shadow 진입시점을 변경하지 않음.
- 과거 시리즈는 베타 이력으로 보존. 2026-10-12 새 ID·초기1억원, USD 환산은 사용자 지정 2026-10-08 1,339.2원/USD. 이전 보유·주문·원신호 승계 없음. 과거 가격은 지표 준비용으로만 사용.
- 늦게 업로드한 자료는 거래일 순서대로 Replay. 각 판단에서는 미래 행 차단. 자료 기준일·수집시각·계산시각·게시시각·원장 반영일 구분.
