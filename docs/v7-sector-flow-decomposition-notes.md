# 해석 유의사항

- Money Flow 점수는 섹터 간 상대 백분위가 포함되므로 시장 전체 순매도 국면에서도 상대적으로 덜 나쁜 섹터가 상위권에 들어갈 수 있습니다.
- V7.2의 점수대 분포는 섹터-거래일 기준입니다. 한 섹터가 여러 날짜에 같은 점수대에 머물면 여러 관측치로 계산됩니다.
- 점수대별 수익률은 `stateForwardPerformance`와 `entryForwardPerformance`를 구분해서 봐야 합니다. 전자는 해당 점수대에 머무른 모든 날짜, 후자는 새로 그 점수대에 진입한 날짜만 봅니다.
- 점수와 향후 수익률의 Pearson/Spearman 상관계수는 방향성과 단조성을 확인하기 위한 진단값이며, 인과관계를 의미하지 않습니다.
- 현재 확정 섹터 매핑을 과거에도 동일하게 적용하므로 과거 편입 변경을 완전히 재현하지는 않습니다.
