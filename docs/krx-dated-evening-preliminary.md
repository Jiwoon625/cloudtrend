# KRX 직전 확정자료 활용 — 저녁 예비 스크리닝 (2026-10-21)

## 목표와 계산 경계

한국 저녁 Preliminary의 당일 Toss 종가·기술점수를 유지하면서, KRX 당일 배치가 아직 발표되지 않았으면 **항목별 실제 마지막 확정 날짜**를 표시한 예비 판단을 제공합니다. 공식 당일 자격·M0·원신호·진입확정·청산·매매수량·Shadow/실제 원장은 기존 아침 Final 그대로입니다. 이 PR에서 기존 계약·완료 세션·소스 파일을 변경하지 않습니다.

- 기존 `krxReviewReferenceParser`의 `KRX_STOCK` / `KRX_ETF` 출처 태그를 통과한 실제 관측만 선택합니다.
- 필수 KRX 기준일의 자동 이월은 **정확히 직전 정규거래일 한 회차**입니다. 주말·휴일을 달력 1일로 계산하지 않으며, 이전보다 더 오래된 값이나 미래일은 예비 계산에서 사용하지 않습니다.
- 주식: 전일 확정 시총과 현재의 다른 실격/보류 조건, 현재 구성된 시가총액 기준선을 함께 보여줍니다. 진입 준비는 보장하지 않으며 기술점수·실제 신호·규모점수를 덮어쓰지 않습니다.
- ETF: KRX 시총과 **최신 실제 관측 20거래일**의 거래대금을 결합합니다. 당일 KRX 거래대금이 없으면 전일자로 끝나는 실제 20개 관측을 사용하고, 어제 값을 오늘 거래대금으로 복제하지 않습니다. 기간 내 하나라도 KRX 정본 거래대금이 없으면 유동성 근거는 미확인입니다.
- 예비 ETF Health = 기존 가중 전 Health 산식 (시총 500억/1000억, 거래대금 10억 등). 예비 M0 = **당일 관측 기술 62.5% + Priority 7.5% + 예비 Health 15% + 현재 계산 가능한 환경 15%**입니다. 계산 불가능한 항목은 0이 아니라 미확인으로 유지합니다.
- ETF 기초지수/MA60은 KRX 출처로 확인한 최대 직전 60거래일의 실제 관측만 참조합니다. 당일 지수 종가·MA60 청산을 추정하거나 체결로 연결하지 않습니다. 완전한 전일 M0가 없으면 예비 신규돌파도 판정하지 않습니다.
- 현행 채택 ETF 범위(주식형·커버드콜)만 예비 M0를 표시합니다. 현금형·채권형은 본래 전략 비대상이므로 현재 참고 관측만 유지합니다.
- 전일 값의 날짜, 시가총액/20일 평균의 개별 기준일, 불완전한 자료·경계 근접 경고를 UI에 표시합니다. 다음 날 오전에 당일 KRX 자료가 오면 기존 최종 산식이 계산되며 예비 항목은 최종항목으로 승격되지 않습니다.

## 데이터 흐름

```
원천 CSV (원본 불변)
  ├─ 동결 전략 계산 -> 기존 공식 score/entry/exit/Shadow 기록 (불변)
  └─ KRX 참고 파서 (항목별 원본 출처·관측일)
        └─ krxPreliminary (읽기 전용, 당일 가격+전일 실제 관측)
             └─ krxReviewReference.preliminary
                  ├─ 국내 대시보드 / 종목 상세 KRX 참고 UI
                  └─ ETF 스크리너 '예비 M0 80점 이상' (확정 진입과 분리)
```

현재 버전의 예비 결과는 저장된 새 스크리닝 계산 결과와 함께 전달되는 UI 참고 계층입니다. 저녁/아침 예비-확정 간 *후보별 변화 비교표* 및 별도 확정 시각 로그는 아직 구축하지 않았으며, 기존 `screening_run_archive`와 별도 비교로 구현해야 합니다.

## 운영 검증 기준

1. 직전 정규거래일만 인정. 주말·연휴와 2거래일 이상 결측 구분.
2. 출처 태그 없거나 20거래일 미충족 시 예비 M0 null.
3. 당일 공식자료 수신 후 예비 결과보다 공식값 우선, 별도 예비 판단은 사라짐.
4. 예비 80점 돌파/시총 적격은 실제 주문/Shadow로 연결하지 않음.
5. 원본 정규 엔진 파서/모델 계산, 완료된 세션, 종전 CSV 해시 불변.
6. 실제 ETF 평가 종가는 Toss 실제 가격을 별도 인증·기준일 대조한 뒤 기록해야 합니다. KRX 전일 이월로 실제 평가원장 결측을 자동 채우는 변경은 하지 않습니다.
