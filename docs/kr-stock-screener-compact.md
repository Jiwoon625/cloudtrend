# 한국 주식 스크리너 간결화

상태 셀에 전체 판단 근거가 쌓여 모바일 한 화면을 차지하는 문제를 해결한다. 기존 PR225의 유효한 부분 판단은 보존하며, 설명의 위치만 목록에서 상세로 옮긴다.

## 범위

- 주식 스크리너: 종목, 섹터, 종가, 기술점수, 기존 점수 변동(1D), 두 줄 상태만 유지한다.
- 시장·우선점수·모델등급·거래량 비율·RS20·RSAccel·52주 고점 거리·시가총액은 목록 열과 열 선택 메뉴에서 제거한다.
- 해당 항목은 주식 종목 상세의 ‘판단 요약 → 전체 근거·Onset 경로 → 상세 지표’에서 확인한다.
- KRX 공표 시각 안내는 표 위에 한 번만 표시한다. 각 행에는 필수 자료 대기 여부만 짧게 표시한다.
- 중요한 경고는 종목명 아래 한 줄과 상세 링크로 유지한다. 상세에서는 원래 경고를 모두 확인할 수 있다.
- ETF·US·대시보드와 매매 판단·주문·Shadow·원장·수집기에는 변경이 없다. 기존 공유 테이블은 명시적인 `compactStock` 모드에서만 축약한다.

## 상태 우선순위

- 확인된 FAIL/RSAccel 미충족/RISK_OFF → ‘진입 제외’. 다른 자료가 미확인이어도 단순 PENDING으로 덮지 않는다.
- 기술 신규 돌파 + 필수 자료 미확인 → ‘8.0 신규 돌파 · 진입 미확정’.
- 실제 보유 → 기술청산 여부를 우선하며 추가 진입으로 표시하지 않는다.
- 미보유·보유 미확인 종목의 9.5점 상향돌파를 목록의 청산 신호로 표시하지 않는다. 상세에서는 ‘보유 시’ 조건 또는 ‘관측 조건 참고’로 구분한다.

## 모바일 계약과 검증 범위

- 상태는 18px 높이의 단일 행 두 개, 총 36px로 제한한다.
- 640px 미만 화면에서는 종목 이름 96px, 상태 160px로 제한하고 셀 좌우 여백을 각 4px로 둔다. 320px 화면에서 페이지 여백 32px와 테두리를 빼도 이름·상태가 함께 보일 수 있는 크기다.
- 표는 모바일 최소 640px, 넓은 화면 최소 720px이며 가로 스크롤을 유지한다. 첫 종목 열은 고정한다. 이는 모든 열이 작은 화면에 동시에 들어간다는 뜻은 아니다.
- 실제 Chromium 실행은 기존 환경의 socket 권한 제한으로 수행하지 않았다. 따라서 위 치수는 CSS/SSR 계약 검증이며 실기기 픽셀 측정 결과가 아니다.
- 회귀는 여섯 핵심 열, 제거된 선택 메뉴, 두 줄 상태, 이름 고정, 경고 축약, 반복 열 숨김/복원과 정렬, 상세 근거·지표 이동, FAIL/PENDING/보유 구분, ETF 분기 보존을 검사한다.

사용자의 명시적인 병합·배포 승인에 따라 검증된 변경을 PR로 반영한다. 운영 배포와 실제 화면 검증 결과는 각각 별도로 기록한다.
