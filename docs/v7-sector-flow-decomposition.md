# CloudTrend V7 · Sector Flow Decomposition

이번 검증은 섹터 로테이션 순위가 자주 바뀌는 원인을 분해하기 위한 진단입니다.

## 비교 순위

- Price Leadership Top4
- Money Flow Top4
- Rotation Score Top4

각 순위별로 Strict/Buffered Top4 체류기간, 5/10/20/40D 생존율, 1D/5D Top4 구성 유지율, 재진입 간격을 비교합니다.

## 4위-5위 경계 점수차

각 점수별로 매 거래일 4위와 5위의 점수차를 저장하고 `<1`, `<3`, `>=5` 구간 비중을 계산합니다. 작은 점수차에서 발생하는 Top4 교체는 강한 경제적 로테이션보다 경계 순위 노이즈일 가능성이 있습니다.

## Money Flow 실질 자금유입 확인

Money Flow Top4에 대해 다음을 따로 집계합니다.

1. 외국인+기관 5일 합산 순매수 > 0
2. 합산 순매수 > 0 + 거래대금 점유율(5일-20일) 상승
3. 외국인과 기관 모두 5일 순매수 + 거래대금 점유율 상승
4. 합산 순매수가 음수인데도 상대순위 기준 Top4인 비율

이를 통해 상대 백분위 점수의 순위 변화와 실제 절대 자금유입을 분리합니다.
