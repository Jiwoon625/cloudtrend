# CloudTrend V7.2 · Sector Score Band Decomposition

V7.2는 섹터 로테이션 점수가 자주 바뀌는 원인을 더 세밀하게 분해하기 위한 진단 백테스트입니다.

## 분석 대상 점수

- Price Leadership
- Money Flow
- Rotation Momentum
- Rotation Score

각 점수는 매 거래일 14개 섹터 간 상대 우위를 0~100점으로 환산한 값입니다.

## 기존 V7 진단 유지

각 점수군별로 다음 지표를 계속 계산합니다.

- Strict / Buffered Top4 체류기간
- 5/10/20/40D 생존율
- 1D/5D Top4 구성 유지율과 신규 진입 수
- 4위-5위 점수차 분포 및 경계 노이즈 비율

## V7.2 추가 진단

점수대는 `0~20`, `20~40`, `40~60`, `60~70`, `70~80`, `80~90`, `90~100`으로 나눕니다.

각 점수군과 점수대별로 다음을 계산합니다.

1. 전체 기간 섹터-거래일 분포
2. 해당 점수대에 속한 고유 섹터 수
3. 해당 점수대 관측치 중 Top4 비율
4. 해당 점수대 신규 진입 횟수
5. 같은 섹터가 해당 점수대에 연속 체류한 평균/중앙/분위수 거래일 수
6. 점수대에 머무른 모든 섹터-거래일 기준 5/10/20/40D 수익률과 KOSPI 대비 초과수익률
7. 점수대에 새로 진입한 시점 기준 5/10/20/40D 수익률과 KOSPI 대비 초과수익률
8. 점수와 향후 수익률·초과수익률 간 Pearson/Spearman 상관계수

## 해석 기준

- 점수대 분포는 섹터-거래일 기준입니다. 한 섹터가 여러 날짜에 같은 점수대에 머물면 여러 관측치로 계산됩니다.
- 점수대 체류기간은 같은 섹터가 같은 점수 구간에 연속으로 존재한 거래일 수입니다.
- `stateForwardPerformance`는 그 점수대에 머무른 모든 날짜를 신호로 본 결과입니다.
- `entryForwardPerformance`는 해당 점수대에 새로 진입한 날짜만 신호로 본 결과입니다.
- 상관계수는 점수와 향후 수익률의 선형/순위 관계를 보여주며 인과관계를 의미하지 않습니다.
- 섹터 수익률은 해당 섹터 구성 종목의 중앙값 수익률입니다.
