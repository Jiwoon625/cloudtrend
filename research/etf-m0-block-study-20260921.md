# CloudTrend M0 블록 기여도 검증 — 2026-09-21

## 결정

**연속형 Technical을 사용하는 기존 4블록 M0의 80점 Onset 진입 + 기초지수 MA60 청산을 잠정 유지한다. Priority·Health·Market/Sector는 이번 실험에서 제거하지 않는다.**

기준 포함 20개 구조를 비교했다. 사전에 정한 학습·검증 동시 개선 조건을 통과한 대안은 0개다. 10종목 기준 전체 기간에서는 기준 모델이 CAGR과 Sharpe 모두 1위였다. 이는 모든 가능한 M0 산식의 전역 최적해라는 뜻은 아니다. 프로덕션 배포 없이 연구 정책·점수/신호 함수·재현 스크립트·자동화 단계에 반영했다.

## 실험 조건

- 주식형 ETF 241개, 2018-01-02~2026-09-18. 현행 분류 대상이며 실제 신호가 발생한 ETF 수는 모델마다 다르다.
- 기본 포트폴리오 최대 10종목, 진입 시 자산의 1/10 이내 배정, 잔여 현금 유지, 보유 중 일괄 리밸런싱 없음.
- 종가 신호 → 다음 거래일 시가 체결. 기초지수 종가 < 기초지수 MA60일 때 청산 신호. 시간 제한 청산 없음.

- 동일 날짜 후보는 종목코드 순서로 배정. 최종 미청산 보유분은 종가 평가하고 가상 매도를 만들지 않음.
- 학습 2018~2022, 검증 2023~2024, 사후 점검 2025~2026-09-18. 각 구간은 현금에서 시작. 연도별 표는 전체 곡선을 나눈 수익률이므로 구간 초기화 결과와 다를 수 있음.
- 학습과 검증 각각에서 기준 대비 CAGR·Sharpe 모두 개선, MDD 악화 3%p 이내, 종료가 확인된 매칭 이벤트 25건 이상이면 통과. 통과 후보는 검증 Sharpe로 선택. 최근 구간은 선택에 사용하지 않음.
- 모든 모델에 기존 공통 eligible 조건 적용. 블록 삭제 모델도 결측 데이터 요건을 완화하지 않아 비교 표본을 유지.

## 블록별 판단

**Priority: 현재는 유지.** 제거 시 전체 CAGR 13.71%→11.68%, MDD −26.05%→−28.38%, 시장 노출 46.19%→68.91%였다. 학습 구간 CAGR도 2.25%→0.41%로 낮아졌다. 매칭 진입 이벤트는 2,841→7,236건으로 늘었다. 이는 실제 포트폴리오 체결 건수가 아니라 중복 보유를 걸러내기 전 유효 후보 이벤트다. Priority가 단순 가점 외에 진입을 엄격하게 하는 역할도 한다는 해석이 가능하다.

현행 Priority는 회전점수가 있을 때 `(규모점수+상대수익점수+rotation/100)/5×100`이다. 각 항목의 최대값이 1이면 블록 최대 60점, M0 기여 최대 9점이다. 회전점수가 없으면 분모 4로 최대 50점/7.5점이다. 명목 배점 15와 실제 도달 가능 범위가 어긋난다. 다만 집계 패널에는 원시 하위항목과 회전점수 결측 여부가 없어 정확한 분모 수정은 하지 않았다. 모든 P에 1/0.6배를 적용한 가설 실험은 CAGR 9.13%로 악화됐다. **범위 불일치는 문서화하되 이를 기계적으로 늘리는 수정은 채택하지 않는다.**

**Health: 현재 점수 방식을 유지.** 제거 시 학습 CAGR은 2.25%→6.44%로 좋아졌으나 검증 CAGR은 8.88%→2.04%로 악화됐다. 전체 CAGR은 8.54%다. Health를 점수에서 빼고 기존 Health≥75 조건만 두어도 전체 CAGR 8.66%에 그쳤다. 단, 집계 Health 조건은 실제 AUM·거래대금·괴리율을 각각 확인하는 편입 필터와 다르다. 원시 시점별 품질 데이터를 이용하는 개편 가능성까지 기각한 결과는 아니다.

**Market/Sector: 현재는 유지.** 제거 시 전체 CAGR 10.36%, 검증 CAGR 5.17%로 기준보다 낮았다. 다만 전체 MDD는 −22.40%로 완화됐다. 수익을 희생해 낙폭을 줄이는 대안은 될 수 있지만, 이번 수익·위험 동시 개선 조건에는 부합하지 않는다.

전체 일별 표본에서 Priority–Health 상관은 0.495, 연속형 Technical–Market/Sector 상관은 0.544였다. 중복 가능성은 있으나 완전 중복은 아니다. 단순 상관이나 제거 전후 수익률 차이를 독립적인 인과 기여도로 해석할 수 없다. 블록이 바뀌면 진입 시점·노출·포트폴리오 배정이 함께 달라지기 때문이다.

## 반영한 정책과 남은 과제

`M0 = 0.55×연속형Technical + 0.15×Priority + 0.15×Health + 0.15×Market/Sector`

각 블록은 원래의 0~100 스케일을 사용한다. 연속형 Technical은 가격/구름대, MA20/MA60, MA60/MA120, 가격/MA20, MA60의 5일 기울기를 20일 후행 변동성으로 나누고 각각 `clip(50+25×gap/vol,0,100)` 후 평균한다. 변동성 하한은 0.003이며 유효 이력 조건을 유지한다. 현행 M0 전체에 EMA를 씌우는 방식과는 다르다.

진입은 `전일 M0<80, 당일 M0≥80`, 청산은 `기초지수 종가<MA60`이다. 연구 코드의 점수/신호 함수와 정책 JSON에 명시했고, 다음 연구 실행에도 블록 비교가 포함되도록 워크플로를 추가했다. 기존 서비스 화면이나 실거래 로직을 배포·교체한 것은 아니다.

향후 구조 변경에서 우선할 일은 (1) Priority 하위항목별 실효 배점 및 결측 처리 정합성, (2) 실제 시점별 AUM·유동성·괴리율을 이용한 Health 필터, (3) 현재 구성종목 기준 생존편향 제거와 분배금·수정주가 정합성, (4) 종목코드 순서에 좌우되지 않는 포트폴리오 배정 검증이다. 이번 집계 패널만으로 이 문제들을 해결했다고 주장하지 않는다.
